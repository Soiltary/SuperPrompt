﻿SuperPrompt (version 2)
====================

[English]

Your personal, offline prompt generator for Windows. Write what you need in your own
words (Saudi dialect, formal Arabic or English) and SuperPrompt writes a structured prompt
you can paste into Claude Code, Codex, ChatGPT or any assistant.
Nothing is sent to the internet: no fonts, scripts, images, analytics or AI calls.

How to start
1. Double-click "Start SuperPrompt.bat" in this folder.
2. A small black window opens and your browser opens http://127.0.0.1:8765/
   (if that port is busy, the next free one is used; keep using 8765 so your saved data stays).
3. Keep the black window open while you use SuperPrompt. Close it to stop.
You can also double-click "index.html" directly; everything works the same, but the browser
keeps saved data separately for each address (use History > Export / Import to move it).

Using it
- Goal: write the request; keep paths, versions and error codes as they are; they are kept exactly.
- Existing prompt or earlier request: paste a prompt to improve it, then write your correction
  in the goal box. The latest instruction wins and you get one complete prompt.
- Advanced options: mode (Auto + 10 modes), detail level (short / balanced / detailed),
  target assistant (agent with tools / chat without tools / generic), format, and 2 alternatives.
- After generating: "What I understood" shows the mode (change it with one click), the topic,
  kept literals, protected items and unknowns. If a key fact is missing you get 1-2 quick questions.
- Result: read, Edit, Copy, Save to history, Regenerate. Ctrl+Enter generates.
- History: search, open, edit, copy, delete, export and import (old and new export files).

Saved on this PC only (browser storage): theme, interface language, settings, last goal,
existing prompt, output language, last result and history. Old history from version 1 is
upgraded automatically the first time you open version 2; nothing is deleted.


[العربية]

مولّد برومبت شخصي يعمل بدون إنترنت على Windows. اكتب اللي تبغاه بكلامك
(باللهجة أو الفصحى أو الإنجليزي)، وSuperPrompt يكتب برومبت منظّم تلصقه في
Claude Code أو Codex أو ChatGPT أو أي مساعد.
ما يُرسل أي شيء للإنترنت: لا خطوط ولا سكربتات ولا صور ولا أدوات تحليل ولا ذكاء اصطناعي سحابي.

طريقة التشغيل
1. انقر نقرًا مزدوجًا على "Start SuperPrompt.bat" داخل هذا المجلد.
2. تفتح نافذة سوداء صغيرة، ويفتح المتصفح العنوان http://127.0.0.1:8765/
   (وإذا كان المنفذ مشغولًا يُستخدم التالي؛ خلك على 8765 عشان تبقى بياناتك المحفوظة).
3. خل النافذة السوداء مفتوحة أثناء الاستخدام، وأغلقها للإيقاف.
وتقدر تفتح "index.html" مباشرة، وكل شيء يشتغل نفس الشيء، لكن المتصفح يحفظ البيانات
لكل عنوان على حدة (انقلها من السجل عبر تصدير / استيراد).

طريقة الاستخدام
- الهدف: اكتب طلبك، والمسارات والإصدارات ورموز الأخطاء تنحفظ مثل ما كتبتها.
- برومبت موجود أو طلب سابق: الصق البرومبت لتحسينه، واكتب تصحيحك في خانة الهدف؛
  الأحدث يغلب ويطلع لك برومبت واحد كامل.
- الخيارات المتقدمة: النمط (تلقائي + 10 أنماط)، ومستوى التفصيل (مختصر / متوازن / مفصّل)،
  والمساعد المستهدف (ينفّذ على الجهاز / محادثة بدون أدوات / عام)، والشكل، وبرومبتين بديلين.
- بعد التوليد: «اللي فهمته» يعرض النمط (تقدر تغيّره بضغطة) والموضوع والمحفوظ حرفيًا
  واللي ما ينلمس وغير المعروف. وإذا نقصت معلومة مهمة يطلع لك سؤال أو سؤالين سريعة.
- النتيجة: قراءة، وتعديل، ونسخ، وحفظ في السجل، وإعادة توليد. وCtrl+Enter للتوليد.
- السجل: بحث، وفتح، وتعديل، ونسخ، وحذف، وتصدير واستيراد (ملفات النسخة القديمة والجديدة).

يُحفظ على هذا الجهاز فقط (تخزين المتصفح): المظهر ولغة الواجهة والإعدادات وآخر هدف
والبرومبت الموجود ولغة المخرجات وآخر نتيجة والسجل. وسجل النسخة الأولى يتحدّث تلقائيًا
أول ما تفتح النسخة الثانية، بدون حذف أي شيء.
