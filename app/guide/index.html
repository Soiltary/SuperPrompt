User Guide

How to get the best prompt from SuperPrompt: modes, options, questions, corrections and history

Start with One Sentence in Your Own Words

Write the goal the way you would say it: «الويندوز ما يرضى يثبت التحديث»، «كمل من آخر نقطة»، or 'add dark mode to my app'. Dialect, formal Arabic and English all work, even mixed

Add the facts you already have: paths like C:\Projects\App v2, versions, error codes, what you tried and what happened, and anything that must not be touched. These are kept exactly as written and shown separately from what is still unknown

Auto Mode and the Ten Modes

Auto picks the mode for you and shows it after generating; you can switch it with one click. Quick: a short, direct prompt. Comprehensive: priorities and acceptance criteria. Diagnose: symptoms, what changed, what was tried, read-only checks, ranked causes, smallest fix and a retest. Project: read the current state, back up, never rebuild from scratch, test end to end

Review: criteria, real evidence, a verdict per criterion and honest limits. Research: criteria, recent official sources and a comparison table. Improve: keeps your intent and constraints and merges corrections. Learn: level, step-by-step, examples and self-check. Resume: last confirmed point, no repeats, a resume point after each batch. Files: exact paths, copy and verify before removing, one final copy, space before and after

Detail Level, Target Assistant and Format

Detail level: Short keeps only the essentials, Balanced is the everyday default, Detailed adds evidence rules and a report table

Target assistant: 'Agent' is for assistants that can run tools on your PC (like Claude Code or Codex), it says do it yourself within these permissions and verify. 'Chat' is for assistants without tools, it asks for numbered steps with the expected result of each. 'Generic' stays neutral

Format: Sections with headings, plain Paragraphs, or one numbered list of Steps. Turn on alternatives to get two extra versions, such as a short execution prompt and a chat-steps version

When SuperPrompt Asks You a Question

If a missing fact would change the work, calories for a meal plan, the error text for a crash, the source and destination for a file move, you get one or two questions with quick answers and a free-text box

Answer and press 'Use my answers', or press 'Continue with the stated assumptions'. Either way you already have a complete prompt; the assumptions are written in it so the assistant does not invent anything

Improve a Prompt or Add a Correction

Open 'Existing prompt or earlier request', paste the prompt, and write your correction in the goal box: «تصحيح: لا تحذف D:\old، خله نسخة احتياطية، وبدل E:\new خلها F:\work\new». The latest instruction wins and is merged where it belongs

You get one complete, ready prompt, never a list of differences. Parts you confirmed ('this works now') are marked as confirmed so they are not retested

History, Export and Import

Every generated prompt is saved in History with its goal, mode and options. Open one to load it back into the generator, edit and save it, copy it, or delete it

Export writes a JSON file you can keep as a backup or move to another browser; Import accepts both the new and the old export format. The browser keeps data per address, so use the same launcher each time

Frequently Asked Questions

Quick answers to common questions

What exactly is a meta-prompt? +

A meta-prompt is a prompt that writes another prompt. Instead of drafting the final instruction for an AI model yourself, you describe what you want, and the tool turns it into a complete instruction with a role, context, task, constraints and output format. You get a well-organised prompt without having to learn prompt-writing techniques first, and you can still edit every line before you use it

How do I correct a prompt I made earlier? +

Open «Existing prompt or earlier request» under the goal box and paste the earlier prompt or request. Then write only the change in the goal box, for example «make it 10 slides, not 15» or «don't delete D:\old, keep it as a backup». The latest instruction replaces the old one where it belongs, and you get one complete updated prompt, not a list of differences

Which AI models do the generated prompts work with? +

Any chat model that accepts text, including ChatGPT, Gemini, Claude, Copilot and assistants built on open models. The prompts are plain text with clear headings, so they also fit tools that let you save custom instructions or reusable templates

Do you store what I type or collect my data? +

Nothing is sent anywhere. Your goal, chosen language, last result and history are saved only in this browser's local storage on your computer. You can delete single entries or clear everything from the History page

In which languages can I generate prompts? +

Ten: Arabic, English, French, Spanish, German, Turkish, Portuguese, Japanese, Korean and Chinese. Headings and instructions are written in the language you choose, and Arabic prompts read right-to-left

Why do I need a prompt generator at all? Can't I just type my request directly? +

You can, but a short request leaves the assistant guessing what changed, what was tried, what must not be touched and how to prove it worked. SuperPrompt adds exactly those parts, read-only checks first, boundaries, verification at the point of use and a report, so the first answer is usually the useful one

Can I use the generated prompts commercially? +

Yes. The prompts you create are yours to use in personal or commercial work. Check the terms of the AI service you paste them into, and review its answers before you publish or rely on them
